# 18 - Tech Stack

## Frontend (Mobile)
- **Framework**: Flutter
- **Language**: Dart
- **State Management**: Riverpod (`flutter_riverpod`)
- **Routing**: GoRouter
- **Networking**: Dio

## Backend (API)
- **Runtime**: Node.js
- **Framework**: Express.js
- **Database**: MongoDB (Atlas)
- **ODM**: Mongoose
- **Authentication**: JSON Web Tokens (JWT) & bcryptjs
- **Validation**: Joi
- **Media Storage**: Cloudinary (via Multer)

## Future Technologies
- **Real-time**: Socket.IO & Redis (For messaging and live notifications).
- **CI/CD**: GitHub Actions (Linting, Testing, Docker builds).
- **Deployment**: Docker containers orchestrated via Kubernetes or AWS ECS.
