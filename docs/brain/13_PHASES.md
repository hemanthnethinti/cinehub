## Definition of Done (DoD)
For a phase to be considered complete:
1. Feature implemented matching UI guidelines.
2. No business logic in UI widgets.
3. Connected to backend APIs (no mock data).
4. `flutter analyze` passes with 0 issues.
5. High test coverage on UseCases and Repositories.
6. `docs/brain` updated to reflect the new state.
